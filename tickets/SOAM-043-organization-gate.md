# SOAM-043: Review fixed-capacity organization before continual integration

## Recommended thinking

**xhigh** — Separate evidence of learned organization from useful fixed scaffolding and constrain the integrated system claims.

## Problem / hypothesis

The program must decide what organization mechanism, if any, is justified before calling the integrated architecture self-organizing.

Specification: [SOAM v0.2](../docs/RESEARCH_SPEC_V0_2.md).
Apply the [common completion requirements](README.md#completion-requirements).

## Scope

- Review organization, replay, retention, cue/handover, and causal-ablation evidence against the frozen criteria.
- Choose an integration configuration and explicit claim limits; consider simple replay/fixed organization when learned organization has no advantage.

## Acceptance criteria

- [ ] Record proceed/revise/stop and the selected configuration with all failures and budget differences.
- [ ] A proceed with fixed organization must explicitly retain the negative learning result and leave self-organization unsupported.
- [ ] Identify whether learned scope/consolidation or structural growth deserves a separate bounded study; do not make those mechanisms mandatory without evidence.
- [ ] Preserve independent composition, grounding, control, and acquisition gates for continual integration.

## Metrics / evidence

Expected report: reports/ORGANIZATION_GATE.md, linking measured organization and replay artifacts. A negative organization result may justify a scoped integration control, never an affirmative self-organization claim.

## Dependencies

- [SOAM-042](SOAM-042-fixed-capacity-organization.md) — required completed prerequisite; decision prerequisites must record proceed.

## Completion record

Not started. Record actual commands/results, report/artifact links, source/configuration/seed
provenance, supplied scaffolding, negative results, and the effect on downstream readiness.
Set decision to proceed, revise, or stop only when the review is complete.
